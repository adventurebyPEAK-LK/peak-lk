# Peak.lk Website

A modern responsive outdoor adventure and camping gear rental website.

## Files
- index.html - Main website
- style.css - Design and responsive styling
- script.js - Gear filters, booking modal, and form interactions

## Run
Open index.html in a browser.

## Note
This is a frontend prototype for a campus project. Images are loaded from Unsplash and forms currently show demo alerts. A backend (PHP/MySQL or Node.js) can be connected later for real user accounts, bookings, inventory, and admin management.


## Custom Banner
- peak-banner.jpg is the uploaded Peak.lk brand banner used as the homepage hero background.
